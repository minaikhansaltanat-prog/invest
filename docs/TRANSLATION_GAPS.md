# TRANSLATION_GAPS: аударма аудиті

Мақсат: төрт тілдегі (kk, ru, en, zh) интерфейс мәтіні мен бастапқы контентті тексеріп, бос, аударылмаған не басқа тілдің мәтіні қалған жолдарды тізімге шығару. Негізгі талап: `/kk` бетінде орысша не ағылшынша мәтін қалмауы керек. Файл ішінде құпия жоқ.

## 1. Қорытынды

| Тексеру | Нәтиже |
| --- | --- |
| Интерфейс кілттері (`messages/*.json`) | 335 кілт, төрт тілде де бар, жоқ кілт 0 |
| Бос мән (интерфейс және seed) | 0 |
| Seed контенті (`content/seed`) | 1633 мәтін, әрқайсысы төрт тілде |
| Дерекқордағы контент (`npm run audit:content`) | 53 құжат/global, бос не жетіспейтін тіл өрісі 0 |
| Көрінетін беттер (23 бет, төрт тіл, 1440 px) | `/kk` ішінде орысша мәтін жоқ; ru, en, zh ішінде басқа тілдің мәтіні жоқ (тіл ауыстырғыш белгілері мен бренд тақырыпшасынан басқа) |
| Fallback | Payload-та `fallback: false`, интерфейсте жоқ кілт `⟦кілт⟧` болып көрінеді: қазақша мәтін басқа тілде жасырын көрінбейді |

Ауыстырғыш белгілері барлық тілде бірдей: **ҚАЗ, РУС, ENG, 中文** (`src/i18n/config.ts`). Сондықтан ru, en, zh беттерінде осы белгілер кириллицада көрінуі дұрыс және ақау емес.

## 2. Қалай тексерілді

1. `npm run audit:translations`: барлық кілт пен seed мәтінін төрт тілде салыстырады. Бос мән, тілдер арасында бірдей жазылған жол (`kk = ru`, `kk = en`, `ru = en`), қазақша мәтіндегі орыс шылаулары мен ағылшынша тіркестер, ru ішіндегі қазақ әріптері, en/zh ішіндегі кириллица, zh ішінде иероглифтің жоқтығы, ru-ге қарағанда тым қысқа не тым ұзын аударма. Ашық белгі қалса, шығу коды 1.
2. `npm run audit:content` (dev сервері мен дерекқор қосулы кезде): Payload-тан әр құжат пен globalды төрт тілде `fallbackLocale: false` арқылы оқып, қазақшада бар, бірақ басқа тілде бос өрісті табады. Тек оқиды.
3. Браузер сканері: Playwright (Edge) 23 бетті `/kk`, `/ru`, `/en`, `/zh` бойынша ашып, көрінетін мәтін мен `alt`, `aria-label`, `title` мәндерінде басқа тілдің әріптері мен орыс шылауларын іздеді.
4. Қолмен қарау: эвристика жалған белгі де береді, сондықтан әр белгі қаралып, қабылданғаны `scripts/translation-audit.ts` ішіндегі `accepted` тізіміне санатымен жазылды (4-бөлім).

Шектеу: құрал аударманың сапасын емес, толымдылығы мен тілдің араласуын тексереді. Ru, en, zh аудармасын тілші оқып шығуы керек.

## 5. «Жоба нұсқасы» белгісі

Ru, en, zh аудармасы тілші тексермегендіктен «жобалама» мәртебесінде қалды: әр контент бірлігінің `translationStatus` өрісінде kk = «Бекітілді», ru/en/zh = «Жобалама» (`src/seed/index.ts`, `statuses`). Бұл аудитте өзгертілген жоқ. Тілші ru/en/zh мәтінін қарап шыққаннан кейін әкімшіде мәртебе «Бекітілді» болып ауыстырылады. Интерфейс кілттеріндегі «Жоба» белгілері (`page.docDraft`, `scoring.draftBadge`) құжат пен әдістеме жобасына қатысты, аударма мәртебесіне қатысы жоқ.

## 6. Қайта жүргізу

```bash
npm run audit:translations            # консольға; ашық белгі болса, шығу коды 1
npm run audit:translations -- --write # осы файлдың автоматты бөлімін жаңартады
npm run db:dev && npm run audit:content   # дерекқордағы бос тіл өрістері
```

Жаңа мәтін қосқанда: төрт тілді бірге жазыңыз (`t(kk, ru, en, zh)`, `messages/*.json`), содан кейін аудитті жүргізіңіз. Мәтін әдейі бірдей жазылса (атау, шаблон), `scripts/translation-audit.ts` ішіндегі `accepted` тізіміне санатымен қосыңыз.
