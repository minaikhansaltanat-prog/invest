## Жоспар (қысқаша шешімдер)

- Стек: Next.js 16 (App Router) + Payload 3.93 + PostgreSQL, Tailwind v4, next-intl 4, TypeScript strict, Vitest, Playwright.
- Түбір: `kfca-portal/` (репозиторий). Басты бет мәтіндері Payload `home` global-ынан, интерфейс мәтіндері `messages/*.json`-нан, бастапқы контент `content/seed/*` ішінен егіледі (seed).
- Docker жоқ болғандықтан әзірлеу базасы: embedded Postgres (`npm run db:dev`), өндіріс жолы: `docker-compose.yml`.
- Дизайн: эталон құрылымы мен токендер сақталады, бірақ шеберлік деңгейі көтеріледі (қозғалыс, текстура, көлеңке қабаттары, ою-өрнек, микро-әрекеттер). Тек `transform` мен `opacity` анимацияланады.
- Әр кезең соңында: lint + typecheck + test, Playwright скриншоты (`docs/screens/`), commit `stage-N: ...`, осы файлды жаңарту.

## Болжамдар (шешім күтеді)

1. **Жоба түбірі.** Жұмыс папкасы `Portal/`, репозиторий түбірі `kfca-portal/` (ТТ 13.2). `ZH.jpeg` ата-папкада (`Portal/ZH.jpeg`) табылды, ол тек оқылды, түпнұсқа өзгертілмеді.
2. **main тармағы.** Репозиторий бос болды, сондықтан `git init -b night-build` жасалды. `main` жасалған жоқ: таңертең өзіңіз қосасыз.
3. **Docker жоқ.** Бұл компьютерде Docker мен Postgres табылмады. Әзірлеу үшін npm-дағы `embedded-postgres` қолданылады. `docker-compose.yml` өндіріс жолына дайындалады, бірақ түнде іске қосылып тексерілген жоқ.
4. **Дизайн қайшылығы.** `Portal/CLAUDE.md` «эталонды жақсартпа» дейді, ал соңғы нұсқау дизайнды берілгеннен жоғары деңгейге шығаруды сұрады. Соңғы нұсқау басым: құрылым, мәтін, токендер, бөлімдер реті эталондағыдай, ал орындау сапасы (детальдар, қозғалыс, текстура) көтеріледі.
5. **Аударма саясаты.** ТТ 11.2 бойынша бекітілмеген аударма тізімнен жасырылады. Түнгі аудармалар жобалама, сондықтан `settings.translationPolicy` қосылды: `allow-draft` (іске қосуға дейін) және `approved-only` (іске қосқанда). Қазақша мәтін басқа тілде ешқашан fallback болып көрінбейді.
6. **Zh фотосына келісім.** Фото клиенттің NIGHT_TASK нұсқауымен берілді, сондықтан seed-те `consent = true`, себебі «клиент нұсқауы» деп жазылады. Жазбаша келісім файлын тіркеу керек. `consent = false` болса, сайт монограмманы көрсетеді.
7. **Zh фотосының кадры.** Түпнұсқа ақ үстелдегі басылған фото. Түпнұсқа көшірмесі сақталады, ал беттегі 4:5 кадр сол көшірмеден қиып алынған туынды файл.
8. **TypeScript нұсқасы.** npm-да TypeScript 7 шықты, бірақ Next/Payload құралдарымен үйлесімі белгісіз, сондықтан 5.x тұрақты нұсқа бекітілді.
9. **Компьютердегі PostgreSQL 16.** Бұл компьютерде 5432 портында жүйелік `postgresql-x64-16` қызметі жұмыс істейді (сіздің өз серверіңіз). Оған тиілген жоқ, құпия сөз болжанған жоқ. Әзірлеу базасы өз бинарларымен 54329 портында іске қосылады, ал `docker-compose.yml` хост порты 5433.
10. **Жолдағы қазақ әріптері.** Жоба папкасының атауында (`Жанар апай Қауымдастық`) Windows ANSI кодтауына сыймайтын қазақ әріптері бар. Нәтижесінде native `initdb.exe` жолды оқи алмайды. `scripts/db.mjs` барлық жолды 8.3 қысқа ASCII атауына (`D5B9~1`) ауыстырып шешеді. Сондай-ақ `npm install` осы жолда бір рет тұрып қалды, сондықтан `node_modules` ASCII жолында (`C:\tmp\kfca-npm-test`) орнатылып, көшірілді. Таңертең `npm install` тұрып қалса, жобаны ASCII жолына (мысалы, `C:\work\kfca-portal`) көшіріңіз.
11. **Node нұсқасы.** Payload 3.93 `node ^22.23.4 || >=24.22.1` талап етеді, ал мұнда 24.17.0 (тек ескерту, жұмысқа кедергі болған жоқ).
12. **Playwright браузері.** Playwright-тың өз Chromium-ы жүктелген жоқ: Windows-та жүйедегі Edge қолданылады (`channel: msedge`).

## Аударма жобасы ескертпесі

`messages/*.json` және `content/seed/*` ішіндегі барлық аудармаларды (ru, en, zh және қазақ мәтіндері) түнде Claude жазды. Бұл аударма жобасы: ана тілді тілші тексеруі қажет, әсіресе қытайша және қазақша мәтіндер. Қытайша мәтіндер ТТ-дағы серіктес материалдарының терминологиясына сүйенді.

## Жалғастыру нұсқаулығы

1. `git log --oneline` және осы кестеге қара.
2. `npm run db:dev` (embedded Postgres), `npm run dev` (http://localhost:3000).
3. Тексеру: `npm run lint && npm run typecheck && npm test`.
4. Скриншоттар: `docs/screens/`.
