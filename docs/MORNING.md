## 2. Іске қосу (4 команда)

Алдымен `kfca-portal/` ішіне кіріңіз. `npm install` осы жолда (қазақ әріптері бар) тұрып қалса, жобаны ASCII жолына көшіріңіз, мысалы `C:\work\kfca-portal`. Docker орнатылған болса, `npm run db:dev` орнына `docker compose up -d` (`docker-compose.yml`) қолдануға болады: `.env.example` файлын `.env` деп көшіріңіз (порт 5433 `DATABASE_URL` ішінде дайын).

```bash
npm run db:dev     # 1-терминал: embedded PostgreSQL (порт 54329), ашық қалады
npm run seed       # бір рет: 4 тілде бастапқы контент (38 бет, қызметтер, мысал жобалар)
npm run dev        # 2-терминал: http://localhost:3000 (әкімші: /admin, бірінші әкімшіні өзіңіз жасайсыз)
npm run lint && npm run typecheck && npm test && npm run test:e2e   # тексеру
```

Бірінші әкімші: `/admin` ашыңыз, пошта мен құпия сөзді (кемінде 12 таңба, әріп пен сан) өзіңіз енгізесіз, ол автоматты түрде супер-администратор болады. Түнде ешқандай құпия кілт жазылмады (`.env` қолданылмаған).

## 3. Шешім күтетін болжамдар (маңыздылары)

Толық тізім: [PROGRESS.md](PROGRESS.md) «Болжамдар» (60 тармақ). Таңертең бірінші шешу керектері:

1. **Дизайн қайшылығы.** Жоба `CLAUDE.md` «эталонды жақсартпа» дейді, ал соңғы нұсқау дизайнды жақсартуды сұрады. Соңғы нұсқау басым болды: құрылым мен мәтін эталондағыдай, орындау сапасы көтерілді. Қаламасаңыз, дизайн жақсартуларын (№13 тармақ) өшіруге болады.
2. **Аударма саясаты.** ru/en/zh мәтіндерінің бәрін түнде Claude жазды (жобалама). Іске қосуға дейін `allow-draft`, ана тілді тілші тексергеннен кейін `approved-only` қою керек. Әсіресе қытайша және қазақша мәтіндер мен әкімшілік қазақ интерфейсі (`src/i18n/admin-kk.ts`).
3. **ТТ-да дерегі жоқ орындар бейтарап жазылды** («бекітілгеннен кейін жарияланады»): жұмыс уақыты, байланыс поштасы, жарна мөлшері, мерзімдер (тексеру, бағалау, шағымды қарау), басқару органдарының нақты өкілеттіктері, сыбайлас жемқорлыққа қарсы тәртіптің толық мәтіні, дерек сақтау мерзімі, зияткерлік меншік және дау шешу тәртібі, мүшелік санаттарының айырмашылығы, құжат тізімі, серіктес пен мүше аттары, тұлғалар профилі, нәтиже сандары, Орталық Азия арнасы, Қытай менеджерінің аты, WeChat аккаунты. Нақты материал жоқ бөлімдер (іс-шара, бейне, фото, серіктес, құжат, жаңалық) бос күймен көрсетіледі.
4. **Zh фотосына келісім.** Фото NIGHT_TASK нұсқауымен берілді, сондықтан сидте `photoConsent = true` («клиент нұсқауы»). Жазбаша келісім файлын тіркеу керек; `false` қойсаңыз, сайт монограмманы көрсетеді.
5. **Docker жоқ.** Орналастыру файлдары (`Dockerfile`, compose, Caddy, backup) жазылды, бірақ іске қосылып тексерілмеді (образ жиналған жоқ). Өндіріс жолының Docker-сыз бөліктері тексерілді: `next build` + `next start` жергілікті, DB миграциясы таза базада. Алғашқы staging орналастыруында `docker compose build` және §6 DEPLOY.md бойынша миграцияны тексеріңіз. Postgres 5432 портында сіздің жүйелік `postgresql-x64-16` қызметіңіз жұмыс істейді: оған тиілген жоқ, әзірлеу базасы 54329 портында.
6. **Email.** SMTP адаптері орнатылмаған (жаңа пакет қосылмады): хаттар консольге жазылады, өтініштер админкада «Өтініштер» бөлімінде. Құпия сөзді қалпына келтіру және пошта растау осы себепті жасалмаған.
7. **Әкімші 2FA.** Өндірісте әдепкіде міндетті, әзірлеуде өшірулі (`ADMIN_2FA=on` қосады). Тексеру үшін `.env` ішіне `ADMIN_2FA=on` жазыңыз, кіріп, `/kk/account/2fa` бетінде 2FA қосыңыз.
8. **Деректер бөлмесі.** PDF-ке су белгісін басу үшін `pdf-lib` қажет (орнатылмаған): қазір PDF үстінен CSS су белгісі және журнал, суретке су белгісі басылады. ЭЦҚ (NCALayer) 2-кезеңге қалды. Антивирус (ClamAV) жоқ.
9. **Терминдер.** Глоссарийде жоқ терминдер таңдалды: «Басқарма» (ru Правление, en the Board, zh 理事会), zh «法人联合体», «全体大会», «执行董事», «审计员» және т.б. Тілші тексеруі қажет.
10. **Мысал деректер.** 3 жоба мен 4 жаңалық `isSample`: сайтта «Мысал ретінде көрсетілген» белгісімен тұр. Іске қосу алдында нақтыға ауыстыру керек.
